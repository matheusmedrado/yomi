YOMI - COMANDOS PARA INSTALAR NO COMPUTADOR DA APRESENTACAO
============================================================

Repositorio:
https://github.com/matheusmedrado/yomi

IMPORTANTE
----------
- Instale Git, Python 3.11 de 64 bits e Node.js 20 ou 22.
- Execute estes comandos com internet antes do dia da apresentacao.
- Nao e necessario receber o arquivo yomi_apresentacao_assets.zip.


============================================================
WINDOWS - POWERSHELL
============================================================

1. Clonar o projeto
-------------------

git clone https://github.com/matheusmedrado/yomi
cd yomi


2. Criar e ativar o ambiente Python
-----------------------------------

py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

Se o PowerShell bloquear a ativacao, executar:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1


3. Instalar as dependencias Python
----------------------------------

python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements-notebook.txt


4. Baixar o modelo do detector
------------------------------

New-Item -ItemType Directory -Force local

Invoke-WebRequest -Uri "https://github.com/zyddnys/manga-image-translator/releases/download/beta-0.2.1/comictextdetector.pt" -OutFile "local/comictextdetector.pt"


5. Baixar o modelo do manga-ocr
-------------------------------

python -c "from huggingface_hub import snapshot_download; snapshot_download(repo_id='kha-white/manga-ocr-base', local_dir='local/manga-ocr-base')"


6. Criar os dois CBZs da demonstracao
-------------------------------------

python scripts/create_degraded_sample.py

Devem ser criados:

demo_sample_limpo.cbz
demo_sample_degradado.cbz


6.1 Gerar resultados auditados e paineis visuais
-------------------------------------------------

Este comando executa varios OCRs e pode demorar alguns minutos:

python scripts/evaluate_robustness.py

Devem ser criados:

presentation_artifacts/robustness/results.json
presentation_artifacts/robustness/evidence_low_contrast.png
presentation_artifacts/robustness/evidence_gaussian_noise.png
presentation_artifacts/robustness/evidence_salt_pepper.png


7. Instalar e compilar o frontend
---------------------------------

cd frontend
npm ci
npm run build
cd ..


8. Verificar modelos e instalacao
---------------------------------

python scripts/verify_setup.py --load-models

Resultado esperado:

COMPUTADOR PRONTO PARA A APRESENTACAO.


9. Rodar o site
---------------

python backend/app.py

Abrir no navegador:

http://127.0.0.1:5001


10. Rodar o notebook, se necessario
-----------------------------------

python -m ipykernel install --user --name yomi-pdi --display-name "Yomi PDI (Python 3.11)"
python -m jupyterlab notebooks/01_experimento_pdi.ipynb

Selecionar o kernel: Yomi PDI (Python 3.11)

2. Criar e ativar o ambiente Python
-----------------------------------

source .venv/bin/activate

No Arch Linux, nao use o Python 3.14 do sistema. Use estes comandos no lugar
dos dois comandos acima:

sudo pacman -S uv
uv python install 3.11
uv venv --python 3.11 .venv
source .venv/bin/activate

python --version

npm run build
